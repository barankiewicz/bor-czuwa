# Public branding keeps the existing technical identity

Status: superseded by [ADR 0014](0014-technical-identity-follows-the-public-name.md).

The public name is Bór widzi. The rebrand changes the displayed name and adds a logo while keeping
the existing domain/origin configuration and technical identifiers. Renaming the Android package
would create a separate installed app; changing the web origin or local storage identity would
separate Reporters from their existing Drafts, Reports and withdrawal tokens. We accept technical
identifiers that retain the old name to preserve that continuity. Domain selection and provisioning
remain separate release work.
